## Overview

This record describes a source-first workflow for using AI to search building codes and regulations. The useful starting point is often not an automated design decision or a code-compliance verdict. It is the much simpler task of finding the likely section, locating the primary source, and making the path from question to source easier to review.

The workflow treats AI as a fast research assistant. It can search across likely code and regulation sources, identify relevant language, compare nearby sections, and return links to the material it used. The answer remains provisional until a person opens the source and verifies the jurisdiction, edition or effective period, wording, and applicability.

## Role

Daniel defines the actual construction question, the jurisdiction, the relevant project context, and the level of review required. He opens the cited source, checks the language and status, decides whether the result applies, and escalates material uncertainty to the appropriate building official, design professional, attorney, engineer, or other qualified reviewer.

Codex acts as the search, organization, and source-linking layer. It helps reduce the time spent locating relevant material, but it does not become the authority and does not receive permission to make an unreviewed code conclusion.

## Scope Of Work

The workflow covers early research and source discovery for building codes, regulations, permit requirements, ordinances, and related construction questions. It can help identify likely sources, extract relevant passages for review, compare related provisions, and organize source links alongside the question being researched.

It does not issue approvals, determine legal rights, replace an authority having jurisdiction, certify compliance, stamp documents, or make a final professional determination. Those boundaries remain explicit even when the search result appears straightforward.

## Key Actions

- State the question clearly enough to search.
- Identify the jurisdiction and the relevant code edition, effective period, or regulation status when known.
- Ask Codex to find likely primary and official sources.
- Review the returned links and the language or sections they point to.
- Open the source directly and verify the text, context, status, and applicability.
- Record the source and any unresolved ambiguity next to the research question.
- Route consequential or uncertain conclusions to the appropriate professional or authority for review.

## Important Features

- **Source-first output:** the useful answer includes where the information came from, not only a generated conclusion.
- **Jurisdiction awareness:** the workflow keeps location, edition, effective date, and local adoption in view.
- **Search acceleration:** AI handles the tedious discovery work across public sources and related sections.
- **Human verification:** the reviewer reads the source instead of treating the model's wording as proof.
- **Traceability:** a later reviewer can follow the question back to the source that informed the research.
- **Clear boundary:** discovery and organization are assisted; applicability, approval, and professional responsibility remain human decisions.

## Constraints And Decisions

- AI can return an incomplete, outdated, misread, or incorrectly scoped code answer. A confident response is not evidence by itself.
- A source link is necessary but not always sufficient. The reviewer must confirm that the source is official or otherwise appropriate, current for the question, and applicable to the jurisdiction and project context.
- Building codes and regulations may involve state adoption, local amendments, referenced standards, effective dates, interpretations, permits, and authority-specific decisions.
- The workflow does not treat a search result as legal advice, engineering advice, code approval, or a substitute for a qualified professional.
- When the jurisdiction, edition, question, or source is unclear, the safe state is clarification rather than a guessed conclusion.
- The Connecticut eRegulations portal is included as an example source, not as proof of any particular current code requirement.

## Deliverables

- A clearly stated research question.
- A short candidate answer or set of relevant topics to investigate.
- Links to the primary or official sources used.
- The relevant source language or a concise review-oriented summary.
- Notes about jurisdiction, edition, effective period, status, and unresolved applicability.
- A handoff or review request when the issue requires an authority or qualified professional.

## Outcome

The practical gain is reduced search friction. Instead of spending the first part of the task manually navigating portals, searching variations of the same phrase, and trying to remember where a provision was found, the user can ask AI to locate the likely material and provide the path to it.

The trust model stays deliberately narrow: trust the source after reviewing it, not the model merely because it produced a fluent answer. That makes code research faster without pretending that AI has replaced the person responsible for understanding and applying the requirement.

## Tools And Methods

The workflow uses Codex for natural-language search and organization, official state and municipal portals for primary source material, public regulation databases, source links, and human review. For Connecticut research, the official [eRegulations portal](https://eregulations.ct.gov/eRegsPortal/Browse/RCSA/Title_29Subtitle_29-252_HTML/) is one example of a source that can be opened and checked directly.

The method is intentionally simple: define the question, search for the likely provision, show the source, open the source, verify the context, and record the result or the remaining uncertainty.

## Evidence And Limitations

This record is grounded in Daniel's direct description of using AI for construction code and regulation search, the Construction AI Workflow Lab decision log, the curriculum crosswalk for jurisdiction-specific code and permit research, and the Series 110 simulation boundary that requires a jurisdiction, edition, question, and primary sources before a code conclusion.

The Connecticut eRegulations portal is an official state regulations portal, but this record does not assert a specific current requirement from it. The workflow is about finding and verifying sources, not publishing a code interpretation. Currentness, local amendments, effective dates, authority interpretations, and professional responsibility still require direct review.
