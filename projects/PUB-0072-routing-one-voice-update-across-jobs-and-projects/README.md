# Routing One Voice Update Across Jobs and Projects

## LinkedIn Summary

I can give Codex one voice update that covers several jobs and projects.

The skills I've set up sort through what I've said, identify where each piece belongs, and update the appropriate records. I can move from a conversation about one job to a decision on another project in the same update.

I dictate it together, and the information ends up with the work it relates to.

## Overview

I use one voice update to provide information about several jobs and projects. Codex follows the skills I've set up to separate the information and put it into the appropriate records.

## Role

I supply the context, observations, and decisions through dictation. My skills define how Codex identifies the destination for each part and applies the relevant recordkeeping workflow.

## Scope Of Work

The workflow handles mixed updates that span existing jobs and projects. Each record receives the information associated with that work.

## Key Actions

Codex separates the update into individual facts, decisions, and requested actions. It resolves the relevant existing records and uses the appropriate skills to make the updates.

This lets me move between subjects within a single dictation while keeping the resulting records organized by job or project.

## Important Features

The routing rules are saved in skills, so I can reuse the same process across updates. The information stays connected to its subject even when I dictate several subjects together.

## Constraints And Decisions

Routing depends on identifying the correct destination from the information provided. Uncertainty is preserved when a detail or destination is unclear.

The workflow searches existing records before creating anything new and follows the rules for each type of record.

## Deliverables

The output is a set of updates in the relevant job and project records, with the dictated information organized around the work it describes.

## Outcome

I can provide a combined voice update and later find each part in the record for the relevant job or project.

## Tools And Methods

Voice dictation supplies the input. Codex uses a routing skill and the skills responsible for individual record types to organize and save it in Markdown.

## Evidence And Limitations

This describes my current workflow for routing dictated updates. Correct placement depends on the context I provide and the existing records available to Codex.
