# Exceptionally productive days with remote AI workflows

I've had days recently where I'm comfortably moving four or five projects forward at the same time with Codex.

Bringing emails into the project records, working through estimates, finalizing documentation, writing scripts, and directing changes to AutoCAD drawings. Alongside that, I'm dictating daily notes and summaries of texts and phone calls so the context gets recorded with the right project.

I can direct that work remotely, away from the laptop. Sometimes that's hands free by voice while driving, sometimes while going for a walk or eating lunch.

Those exceptionally productive days have been a real unlock for me. It's a lot of different work to keep moving, and I'm finding I can comfortably handle more of it with AI.

## Overview

I've been using Codex remotely to move several projects forward during the same stretch of the day. The work spans incoming information, estimates, documents, scripts, and drawing updates.

Some days that means comfortably handling four or five projects alongside each other. Those days have changed my sense of how much I can get done away from the laptop.

## Role

I'm directing the work and supplying the project context. I explain what needs to happen, work through the details, and dictate information that needs to become part of the project record.

## Scope Of Work

The workflow includes bringing emails into project records, workshopping estimates, finalizing documentation, writing scripts, and directing changes to AutoCAD drawings.

It also includes daily notes and summaries of texts and phone conversations. That information belongs with the project work, so I dictate the context for AI to organize into the appropriate records.

## Key Actions

I give Codex instructions for the work and context for the project it belongs to. I can move between a document task, an estimate discussion, a script, or a drawing update as different projects need attention.

I also summarize conversations and decisions so they are captured alongside the work. That keeps the information coming in from calls and texts connected to the project it affects.

## Important Features

Remote access lets me direct this work without sitting in front of the laptop for every instruction. I use voice when that fits what I'm doing, including hands free while driving. I also use it while walking or eating lunch.

## Constraints And Decisions

The work involves several separate projects, so the instructions and incoming context need to stay associated with the right one. The remote interaction described here is how I direct and discuss the work.

## Deliverables

Project records incorporating incoming information, estimates worked through, finalized documentation, scripts, and updates to AutoCAD documents. The mix depends on what each project needs that day.

## Outcome

I've had exceptionally productive days using this workflow. Being able to comfortably move four or five projects forward in the same period has been a substantial change in how I handle my workload.

## Tools And Methods

Codex remote access, voice dictation, project context, document workflows, scripting, and AutoCAD document updates.

## Evidence And Limitations

This is my account of how I'm using the workflow. The productivity improvement is a personal observation, without a measured time saving. Client information, project identifiers, pricing, and drawing details are excluded.
