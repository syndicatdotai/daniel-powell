## Overview

This workflow uses Codex and remote computer control to perform routine drawing set maintenance in AutoCAD. The work focuses on documentation that is repetitive, distributed across multiple layouts, and easy to overlook when a set has been revised over time.

The review is organized around the drawing set rather than one isolated edit. Codex can move through the layouts, compare repeated information, inspect cover sheet and title block content, identify discrepancies, and make controlled corrections. Daniel then reviews the completed set before it is issued or relied on.

## Role

Daniel identifies the authoritative project information, defines the review scope, and decides which corrections are appropriate. He remains responsible for the technical content, drawing coordination, and final issue decision.

Codex operates AutoCAD through the remote computer, follows the requested review sequence, compares information across layouts, records unclear items, and performs routine edits that can be checked afterward.

## Scope Of Work

The workflow can support:

- reviewing the drawing set layout by layout;
- updating cover sheets, title sheets, and title blocks;
- checking the sheet index against the layouts present in the set;
- comparing sheet numbers, sheet titles, issue dates, and revision information;
- reviewing notes for incorrect, outdated, or inconsistent wording;
- locating blank fields, missing information, and incomplete repeated data;
- identifying duplicated content or inefficient drafting that should be standardized;
- checking that repeated project information agrees across the set; and
- making controlled routine corrections for final human review.

## Key Actions

1. Open the intended AutoCAD drawing or drawing set through the remote computer.
2. Inventory the available layouts and establish the expected sheet sequence.
3. Identify the authoritative project information and the fields that should remain consistent.
4. Review the cover sheet, title sheet content, sheet index, and title blocks.
5. Compare sheet titles, dates, revision data, notes, and repeated information across layouts.
6. Flag missing, contradictory, stale, or unclear content instead of guessing.
7. Apply controlled corrections where the intended information is established.
8. Review the resulting drawing set before issue.

## Important Features

### Full set review

The workflow treats the layouts as one coordinated document set. This makes it possible to find discrepancies that may not be visible when one sheet is reviewed by itself.

### Title block coordination

Repeated sheet metadata can be compared across the set. This includes sheet titles, issue dates, revision information, and other project fields that should remain consistent.

### Cover sheet and sheet index review

The cover sheet and sheet index can be checked against the layouts that actually exist. Missing sheets, stale titles, and mismatched sequencing can be identified for correction.

### Wording and completeness checks

Notes and repeated labels can be reviewed for incorrect wording, outdated language, omissions, and internal inconsistencies. Items that require technical judgment are flagged rather than rewritten without direction.

### Remote operation

Because Codex can operate the workstation remotely, Daniel can begin routine documentation work without being physically at the AutoCAD computer. The same AutoCAD environment and project files remain in use.

## Constraints And Decisions

The workflow is suited to controlled documentation tasks where the expected information and review criteria are known. It is not a substitute for design judgment, code analysis, or professional review.

Codex should not invent a missing date, revision, sheet title, or project value. When the authoritative information cannot be established from the drawing set or supplied source, the item remains flagged for Daniel.

The review also depends on stable remote access and a readable AutoCAD session. Unexpected dialogs, unresolved external references, damaged files, or conflicting source information may require direct intervention.

## Deliverables

Depending on the assignment, the workflow can produce:

- an updated AutoCAD drawing set with controlled documentation corrections;
- coordinated cover sheet, title sheet, title block, and sheet index information;
- a list of missing, inconsistent, outdated, or uncertain items;
- standardized wording across repeated notes or labels; and
- a drawing set ready for Daniel's final review.

## Outcome

Routine drawing set maintenance can continue while Daniel is away from the workstation. The resulting set has been reviewed more systematically for documentation consistency, and the remaining technical or uncertain items are visible before issue.
