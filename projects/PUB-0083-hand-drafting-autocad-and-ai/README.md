# From Hand Drafting to AutoCAD and AI

## LinkedIn Summary

I learned drafting in school around 2003 to 2005, right as our program was moving from hand drawings to AutoCAD. As I remember it, we were the last class taught the traditional way with pencils, rulers, and protractors, and the first class at the school to start using AutoCAD.

I picked AutoCAD back up about four or five years ago. A lot had changed since those school days, but I still drew by hand when I needed to get something out the door quickly. I can draw something and communicate what I mean without spending much time getting it on paper.

Now AI is helping me keep the documentation more consistent alongside the drawing work. Hand drafting is still useful to me, and it has been interesting to go from learning with pencils and rulers to using AutoCAD with AI helping on the documentation.
