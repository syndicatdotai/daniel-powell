# Publication Rules

## Purpose

This repository is a public record of selected work, not a copy of private project files. Every entry must be understandable without exposing the people, properties, systems, or records behind it.

## Required Exclusions

- Client, customer, employee, subcontractor, and private contact names
- Phone numbers, email addresses, direct addresses, and coordinates
- Internal job numbers, permit numbers, invoices, contracts, and correspondence
- Credentials, tokens, passwords, environment variables, cookies, and private URLs
- Local file paths, private source filenames, and internal wiki links
- Unreviewed photographs, drawings, screenshots, maps, and aerial imagery

## Project Accuracy

- State Daniel's role separately from the overall project scope.
- Distinguish concept, feasibility, drafting, permitting, project management, construction, and completion.
- Do not imply construction was completed when the evidence supports only planning or drawing work.
- Use approximate time and location when exact details increase identification risk.
- Mark memory-based or incomplete records clearly.
- Do not create project-specific facts from general experience.

## Writing Standard

- Use consistent headings and explicit technical verbs.
- Describe actions, methods, constraints, decisions, deliverables, and outcomes.
- Avoid inflated claims, vague praise, and unsupported performance metrics.
- Keep the record useful to a human reader without requiring specialized software.

## Media Standard

- Publish only newly created sanitized derivatives.
- Strip EXIF, GPS, XMP, and IPTC metadata.
- Inspect visible text through OCR and visual review.
- Remove title blocks, addresses, names, signatures, house numbers, license plates, and account information.
- Do not publish a complete private residential plan when selected excerpts communicate the work safely.

## Approval Requirement

Every new project and every material revision requires privacy review and Daniel Powell's explicit approval before publication.
