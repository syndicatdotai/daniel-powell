# Developing a Residential Drawing Package for a General Contractor

A general contractor commissioned drawings for a single-family ranch with an attached garage. The work coordinated the floor layout, exterior elevations, and construction information through successive requested revisions.

Changes included adjusting the garage dimensions to lower its roofline, developing the front entry with columns, and documenting the rear entrance, landing, steps, and railings.

### Coordinating the package

Floor and foundation plans, exterior elevations, construction details, a cover sheet, door and window schedules, and heating-load information formed the package. A front rendering showed the exterior appearance.

Each revision had to carry through the relevant views. Plans described the arrangement, while elevations, sections, notes, and schedules developed the information needed to understand the proposed construction.

### Building a reusable drafting reference

The delivered set later served as a reference for another residential project. The earlier set provided the source drawings for the later project's design development.

The assignment produced a coordinated residential package for the contractor and a reusable drafting reference.
