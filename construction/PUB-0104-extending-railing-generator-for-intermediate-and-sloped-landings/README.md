# Extending Railing Generator for Intermediate and Sloped Landings

A Connecticut railing manufacturer commissioned field measurements and shop drawings for railings on irregular concrete steps. The configuration included stair sections separated by an intermediate landing, with additional landings that were out of level.

Laser and tape measurements established the actual conditions. Those measurements needed to carry through the railing layout so the drawing would reflect the surfaces on which the rails would be installed.

### Turning a job requirement into a software capability

Railing Generator did not yet support the combination of stair sections, intermediate landings, and pitched landings required by this job. The drawing could have been produced manually in AutoCAD.

I used that time to extend the application. The field measurements supplied a real configuration to develop against, and the shop drawings established what the software needed to produce.

### Supporting the measured geometry

The development added intermediate landings between stair sections and support for landings that were out of level. Those features allowed the railing to follow the measured arrangement across the different sections.

AI and dictation supported the workflow, including software development. The project inputs came from the field, and the application changes were directed around those inputs.

A finished shop-drawing PDF and full AutoCAD export were delivered. The same work left reusable capabilities in the generator for future jobs with intermediate or sloped landings.
