## Overview

I did a simple project with AutoCAD, Codex, and Three.js to test using exported CAD linework as the geometry for a browser game with two-dimensional physics. I drew the layout in AutoCAD, exported it, and used Codex to help build the interactive environment.

It was a straightforward experiment in taking work from a drafting tool and using it in a different setting.

## Role

I created the linework and directed how it was used in the browser environment. My familiarity with AutoCAD gave me a comfortable starting point for laying out the geometry, while Codex helped with the implementation.

## Scope Of Work

The workflow connected drawing, geometry export, browser rendering, and physics setup. The exported linework provided the layout; the game implementation gave that layout its interactive behavior.

## Key Actions

- Drew the layout as linework in AutoCAD.
- Exported the linework for use in the browser application.
- Used Codex to help set up the geometry in a Three.js scene.
- Added the physics behavior needed for the experiment.
- Ran the result in the browser and examined how it behaved.

## Important Features

AutoCAD served as the geometry-authoring tool. I used familiar drawing tools to shape the environment before working with it in the browser.

The rendering and physics have separate roles. Three.js displays the scene, while the physics implementation handles the simulated behavior. Three.js documents this separation in its guidance on integrating physics engines. [Three.js physics documentation](https://threejs.org/manual/pages/physics.html)

For this experiment, the game behavior was two-dimensional. Three.js displayed the scene without making the game a three-dimensional movement system.

## Constraints And Decisions

I kept the experiment focused on a simple path from exported linework to an interactive browser environment. Connecting the geometry to the physics behavior was part of that process.

The purpose was to test how these tools could work together on a small game project.

## Deliverables

## Outcome
